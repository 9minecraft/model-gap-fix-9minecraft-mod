# Model Gap Fix 9minecraft Mod - Remove Glitchy Seams From Items

Model Gap Fix 9minecraft Mod is a lightweight, client-side visual enhancement that removes the tiny gaps, seams, and see-through slivers that can appear around the edges of item models. If you have ever noticed thin transparent lines running along the outline of a sword, tool, or any flat item as it is rendered in 3D, this mod cleans them up so every item looks crisp and solid from any angle.
